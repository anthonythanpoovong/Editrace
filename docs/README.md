# Docs

Project documentation, decisions, and customer research.

## Files

- `plan.md` — Project plan and roadmap
- `schema.md` — Template schema documentation
- `architecture.md` — System architecture overview
- `decisions/` — Architectural decision records (ADRs)
- `customers/` — Customer interview notes and GTM research

## Writing Guidelines

- Use Markdown
- One file per decision or customer interview
- Link related documents
- Date all entries
