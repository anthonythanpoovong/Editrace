# Customer research

One file per conversation: `YYYY-MM-DD-<segment>-<short>.md`, copied from [`TEMPLATE.md`](TEMPLATE.md). Log them with `/log-interview` in Claude Code.

These files are the **evidence** `/grill` and `/propose-epic` look for. A proposal backed by "raised" tags from several interviews beats one backed by the author's assumption.

**Privacy:** describe people by role and segment only. No names, emails, handles or confidential details unless they explicitly agreed to be named. No consent, no log.

## Tags

Use these when they fit. Add new ones here when you need them.

| Tag | Meaning |
|---|---|
| `upload-friction` | Getting a video into Editrace is a pain (saving, finding files, watermarks) |
| `link-input` | Wants to paste a link or "send to Editrace" |
| `wants-feed` | Wants to discover trending or viral videos inside Editrace |
| `refilm` | Struggles to match the original's footage (lighting, angle, camera) |
| `template-accuracy` | Comments on how faithful the reconstruction is |
| `tool-howto` | Doesn't know which editor feature produces an effect |
| `mcp` | Uses, or wants, AI clients (Claude, Cursor) driving their editor |
| `editor:resolve` / `editor:premiere` / `editor:fcp` / `editor:capcut` | Their main editor |
| `pricing` | Willingness to pay, current tool spend |
| `time-cost` | How long recreating edits takes today |

Strength per tag: **raised** (unprompted), **confirmed** (agreed when asked), **rejected** (said it's not a problem).
